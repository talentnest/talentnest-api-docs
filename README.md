# TalentNest API

REST API for TalentNest. Live documentation: [api.talentnest.com](https://api.talentnest.com).

The API is served at `https://{subdomain}.talentnest.com/api/v1`. Authenticate with your TalentNest API key (HTTP Basic, key as the username, empty password). Requests must use HTTPS. To request an API key, reach out to your TalentNest Representative or email [support@talentnest.com](mailto:support@talentnest.com).

This repository is the Markdown source for those docs. The published site is the reference for endpoints, parameters, and examples.

Questions: [support@talentnest.com](mailto:support@talentnest.com).
